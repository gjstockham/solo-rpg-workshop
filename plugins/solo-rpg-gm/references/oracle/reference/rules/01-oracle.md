# GM oracle

Original rules for solo-rpg-gm. "Page 1" is this file.

## When to ask
- [p.1] Ask only when the adventure is silent **and** the rules module has no procedure
  for the question (reaction, morale, random encounters, searching and the like come
  first), **and** the answer is significant: a new fact about a named character or place,
  anything that could change the adventure's course, or anything that would noticeably help
  or hurt the party.
- [p.1] Minor, consistent details (a door's colour, a smell, an unnamed guard's remark)
  don't need the oracle. Decide them and move on.
- [p.1] Never decide the answer first and roll for show.

## Framing and likelihood
- [p.1] Ask one yes/no question, phrased so that "yes" is the more interesting answer when
  you can.
- [p.1] Choose the column from what's already established (the adventure, canon, what the
  party has done), before rolling: **very-unlikely**, **unlikely**, **even**, **likely**,
  **very-likely**. If it's certain or impossible, don't roll.
- [p.1] Chance of any Yes result: very-unlikely 20%, unlikely 40%, even 50%, likely 60%,
  very-likely 80%.
- [p.1] Roll secretly: → table `yes-no`, with `--column` and `--secret`.

## Results
- [p.1] **Yes** / **No**: the plain answer.
- [p.1] **Yes, but…** / **No, but…**: the answer holds, with a cost, a limit or a
  complication that softens it.
- [p.1] **Yes, and…** / **No, and…**: the answer holds, and something makes it stronger:
  more help, a worse danger, an extra consequence.
- [p.1] Keep "and" and "but" consistent with the adventure. They colour the answer; they
  never override what the adventure establishes.
- [p.1] Record the question, the likelihood, the result and what it means as canon, so it
  stays true for the rest of the campaign.

## Attitude
- [p.1] When neither the adventure nor the rules module says how a character or creature
  regards the party, roll → table `attitude`. It gives a starting attitude, which play can
  then change.
